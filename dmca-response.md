## Our Project Is an Independent Chinese Idiom Game, Not a Copy of NYT Wordle

wordlechinese.com is a **free, open-source Chinese idiom (成语 chéngyǔ) puzzle game** that has been actively developed since January 27, 2022 — predating NYT's acquisition of Wordle. The project is MIT-licensed and fully open source at https://github.com/fds2003/wordlechinese.

### Key Technical Differences from NYT Wordle

| **Unique features** | Pinyin input, character definitions, idiom encyclopedia, HSK study guides, difficulty categories | None of these |

### Evidence of Independent Creation

1. **Timeline**: The original "Chengyu Wordle" was created by Chee Aun (https://github.com/cheeaun/chengyu-wordle) and launched on January 27, 2022 — before NYT's version existed. Our project is a fork of that independent creation.

2. **Different game mechanics**: Our game uses a custom pinyin-to-character matching system where users type Latin letters that map to Chinese character pronunciations. This is fundamentally different from NYT's English letter-guessing mechanic.

3. **Chinese-specific features**: The game includes pinyin keyboard with tone marks, character definitions from Baidu Baike and ZDIC, idiom difficulty classification, HSK study integration, and a 7,000+ idiom encyclopedia — none of which exist in NYT's Wordle.

4. **Open source history**: The GitHub repository has 411 commits since January 2022, with full commit history demonstrating independent development.

### Legal Basis

The game mechanics of "guess a word with color-coded feedback" are not protectable under copyright law (see Baker v. Selden, 79 U.S. (12 Wall.) 356 (1871)). Our implementation uses entirely different creative expression — different character sets, different visual design, different colors, different input methods, and extensive Chinese-language educational features.

We believe NYT's claim that our game is "an exact copy" is inaccurate. While both games share the common concept of daily word guessing (which is not copyrightable), every expression of that concept in our game is substantially different from NYT's version.
